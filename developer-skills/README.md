# Developer Skills

A compiled, evidence-based snapshot of Aryan's current software-development and DSA abilities.

## Normal use

Read one file:

`developer-skills/SKILL.md`

Examples:

- "Read my developer skills and teach me sliding window."
- "Check developer skills DSA. What should I work on next?"
- "Read my developer skills and compare me with this job description."
- "Based on my developer skills, help me design this backend."

Do not scan the source repositories for normal requests. `SKILL.md` is the compiled state.

## Files

- `SKILL.md`: canonical one-read profile, capability gates, current levels, blockers and weekly calibration rules.
- `REPOSITORY_ANALYSIS.md`: full source-repository audit used only when verifying or refreshing the profile.

## Refresh model

Normal use is cheap:

`SKILL.md -> answer`

A refresh can be expensive:

`changed repositories + questionnaire -> analysis -> updated SKILL.md`

The expensive work is compiled back into `SKILL.md`, so the next conversation returns to one read.

## Standalone repository

This directory is intentionally self-contained. It can be moved unchanged into a future `knownIndie/developer-skills` repository. The connected GitHub tool used to build this does not currently expose repository creation, so the files live under `knownIndie/skills/developer-skills` until an empty standalone repository exists.
